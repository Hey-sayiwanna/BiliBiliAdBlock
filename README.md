# B站去广告（跟随薯薯更新版）

适用于 Surge 的 B站去广告模块。本项目从 [Biliverse/ADBlock](https://github.com/Biliverse/ADBlock) 中抽出去广告功能，精简模块配置，并针对 iPhone、iPad 的实际使用情况做适配。按需跟进薯薯及上游贡献者的更新，当前参考版本为 **v0.7.5**。

## 模块订阅地址

```text
https://raw.githubusercontent.com/Hey-sayiwanna/bilibiliAdBlock/main/bilibiliADBLOCk
```

订阅地址保持不变，后续在 Surge 中点击“立即更新”即可。当前模块版本：**1.4.2**。

## 安装与更新

1. 使用上面的地址安装或更新模块，确认版本为 **1.4.2**；旧模块副本或处理相同接口的其他模块请先停用。
2. 开启模块、脚本、HTTP 重写和 MitM，并安装、完全信任 Surge 证书。
3. 更新模块引用的脚本，等待两个脚本文件下载完成。
4. 完全退出 B站 App 后重新打开。

脚本使用带版本的文件名，减少旧缓存影响。默认搜索词已由模块直接返回完整空响应，不再依赖请求脚本。

## 去广告范围

- 开屏、首页信息流、搜索推荐及搜索结果中的广告。
- 竖屏短视频流及关联短视频流广告，包含“助TA必火”等商业按钮；保留普通竖屏视频和分享按钮。
- 直播信息流、直播推荐、直播 Tab 和直播间商业入口。
- 视频简介区、相关推荐、异步推荐、暂停页、结束页及播放器中明确标识的广告；动态和番剧电影页的广告卡、推广提示与活动弹窗。
- 评论区结构化商业卡、置顶带货推广、编辑器商业入口，以及办卡免流和“流量告急”提示。

保留底部完整导航（包括“会员购”）、“我的”页面、普通评论、非广告活动横幅和动态“最常访问”。本模块优先使用自己的广告选项，避免旧 BoxJS 设置关闭过滤。无法识别并剪除已经录入视频画面的口播或植入广告；接口变化后仍可能需要针对性补充。

## 当前文件说明

| 文件 | 作用 |
| --- | --- |
| `bilibiliADBLOCk` | Surge 模块安装入口，订阅地址保持不变 |
| `scripts/bilibili-json.js` / `scripts/bilibili-json.v1.4.0.js` | JSON 去广告源码与当前运行文件；本次未改动其过滤逻辑 |
| `scripts/bilibili-response.mjs` / `scripts/fix-grpc-headers.mjs` | Protobuf/gRPC 处理入口与客户端兼容适配 |
| `vendor/Biliverse.ADBlock.v0.7.5.v1.4.2.response.bundle.js` | 当前 Protobuf/gRPC 运行脚本 |
| `upstream/` / `scripts/build-vendor.mjs` / `tests/` | 上游源码快照、构建入口与回归测试 |

旧版本产物保留供旧模块引用；当前模块仅引用上表的两个运行文件。

## 构建与验证

使用 Node.js 24 或更高版本，在仓库根目录运行：

```sh
npm ci --ignore-scripts
npm run build
npm test
npm run test:upstream
```

构建从固定的 `upstream/Biliverse-ADBlock-v0.7.5` 源码快照生成当前运行脚本，上游快照保持原样。JSON 接口清理广告卡片；Protobuf/gRPC 接口解码后删除广告字段并重新编码。本地适配保留原始 HTTP/gRPC 错误、异常时放行原响应，并避免同时返回新旧二进制正文。

测试直接执行当前模块引用的脚本，检查广告移除、普通内容保留、iPad 加载兼容、竖屏短视频、压缩响应和未知字段保留。`test:upstream` 执行六组相关回归测试，包含最新 gRPC 状态和原生空响应测试，不包含未接入的设置面板构建测试。故障回归使用重新构造的数据，不包含用户原始抓包、评论、Cookie 或账号信息。
